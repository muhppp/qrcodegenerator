# 🌟 muhp - Premium QR Code Studio

**muhp - Premium QR Code Studio** is a desktop application for generating QR codes, built with Python's `tkinter` library [1, 2]. It features a beautiful, premium user interface designed to provide a seamless and modern experience.

---

## ✨ Key Features

- 🎨 **Modern Dark Theme:** Features a Catppuccin-inspired dark mode design for a sleek and eye-friendly interface [1].
- 📱 **High-Quality QR Generation:** Utilizes the `qrcode` and `Pillow` (PIL) libraries to process and generate high-quality QR code images [1].
- ⚡ **Optimized Performance:** Implements `threading` and `queue` to handle background tasks, ensuring the application window remains highly responsive without freezing [1].
- 📁 **Data & File Handling:** Built-in support for reading `csv` files and managing imports/exports effortlessly via `filedialog` [1].
- 🌈 **Customization:** Includes a `colorchooser` module, allowing users to personalize their styling [1].

---

## 💻 Installation

Download latest release in .exe file and run it normaly or download source code to modify as you like.
The application window will open with a default resolution of 980x680 pixels and supports resizing down to a minimum of 920x620 pixels
